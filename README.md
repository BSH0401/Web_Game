# 🎮 프로게이머 키우기

14살 게이머로 태어나 프로 데뷔, 리그 우승, 월드 챔피언, 은퇴 후 인생까지 키워보는 HTML 인생 시뮬레이션 게임입니다.

👉 **바로 플레이: https://bsh0401.github.io/Web_Game/**

설치할 필요 없이 `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

## 주요 시스템
- **출생 가챠**: 가정 환경(금수저/평범/흙수저)과 피지컬·운영·멘탈 재능을 뽑습니다. 다시 뽑기는 3번까지 됩니다.
- **장르 선택**: 처음엔 다섯 장르를 자유롭게 해보며 숨은 재능(별점)을 찾습니다. 16살에 주력 장르를 정합니다.

  | 장르 | 게임 | 특징 |
  |---|---|---|
  | ⚔️ MOBA | 배틀 오브 히어로즈 | 운영·팀워크 중심, 팀 전력의 영향이 큼 |
  | 🎯 FPS | 택티컬 스트라이크 | 피지컬 중심, 24살 이후 급격히 하락 |
  | 🛸 RTS | 갤럭시 커맨더 | 1:1 개인전이라 개인 실력이 결과를 좌우, 리그 축소 위험 |
  | 🥊 격투 | 파이트 크라운 | 나이가 들수록 노련해짐, 상금은 적지만 인기가 잘 식지 않음 |
  | 🪂 배틀로얄 | 라스트 아일랜드 | 운 요소가 큼, 방송 효율이 높음 |
- **국적 선택**: 한국·중국·일본·미국·독일·브라질 중 고릅니다. 나라마다 인기 장르, 리그 수준, 연봉 수준이 다릅니다.
- **국제대회**: 아시안게임(4년마다, 한·중·일 출전, e스포츠 종목 MOBA·격투·배틀로얄)과 나라 대항전 네이션스컵(2년마다, 모든 나라)이 열리고, 1군 실력자는 국가대표로 뽑힙니다.
- **병역 (한국)**: 26세에 입영 통지를 받습니다(입대 / 1년 연기 / 은퇴 후 입대). 아시안게임 금메달을 따면 병역 특례를 받습니다.
- **장르 전향**: 커리어 도중에도 다른 장르로 갈아탈 수 있습니다. 대신 인기가 절반이 되고 소속팀을 다시 찾아야 합니다. 두 장르 모두 우승하면 특별 칭호를 받습니다.
- **턴 진행**: 1턴은 1분기입니다. 솔로랭크, 팀 연습, 전략 분석, 운동, 방송, 휴식, 학교 공부 중에서 고릅니다.
- **피로 관리**: 무리하면 슬럼프나 손목 부상이 옵니다.
- **특수훈련 (인생당 5회)**: 해외 부트캠프, 피지컬 트레이닝, 멘탈 코칭, 레전드 과외, 재능 각성(1회 한정) 중 하나를 골라 크게 성장합니다.
- **프로 커리어**: 랭크 다이아 이상이면 스카우트 제의가 옵니다. 2군에서 1군으로 승격하고, 스프링/서머 시즌과 플레이오프를 거쳐 월드 챔피언십에 도전합니다.
- **경기 작전**: 주요 경기마다 작전을 고릅니다(장르마다 고위험/안정형/심리전 작전 3가지).
- **랜덤 이벤트 30여 종**: 부모님 면담, 악플, 해외 이적, 국가대표, 연봉 협상 등이 있습니다.
- **메타 변화**: 해마다 장르 인기가 바뀌어 연봉과 인기에 영향을 줍니다.
- **엔딩**: 은퇴 후 진로(코치/해설/스트리머/사업/취업)를 고르면 칭호, 우승 기록, 인생 연표, 점수가 담긴 결과 카드가 나옵니다.

- **랭킹**: 인생이 끝나면 점수가 내 기록 TOP 10에 저장되고, 온라인 랭킹(TOP 50)에 등록할 수 있습니다.

진행 상황은 브라우저에 자동 저장되며, 다음에 접속하면 이어할 수 있습니다.

## 실행
```bash
# 그냥 index.html을 더블클릭해도 됩니다
npx http-server . -p 8765
```

GitHub Pages(Settings → Pages → main 브랜치)를 켜면 웹에서 바로 플레이할 수 있습니다.

## 온라인 랭킹 설정 (Firebase)
1. https://console.firebase.google.com 에서 프로젝트를 만듭니다 (Google 애널리틱스는 꺼도 됩니다).
2. 빌드 → **Firestore Database** → 데이터베이스 만들기 (위치: `asia-northeast3 (서울)`, 프로덕션 모드).
3. Firestore의 **규칙** 탭에 이 저장소의 `firestore.rules` 내용을 붙여넣고 게시합니다.
4. 프로젝트 설정(톱니바퀴) → 일반 → 내 앱에서 **웹 앱(</>)** 을 추가하고, 표시되는 `projectId`와 `apiKey`를 `index.html`의 `const RANK = {...}`에 넣습니다.

> apiKey는 웹에 공개되는 값이라 노출돼도 괜찮습니다. 데이터 보호는 `firestore.rules`가 담당합니다.
